## Русский

Pirate Cinema 0.6.0 заменяет Electron-клиент полностью нативной версией на Rust и Dioxus. Сохранены поиск TorrServer/RuTor и Jackett/Prowlarr, медиатека, русские метаданные, MPV IPC, история просмотра, резервные копии, обновления и системный трей.

Для Windows доступны автономный NSIS-установщик и компактный web-установщик. Для Linux опубликованы DEB, RPM, переносимый архив со скриптом установки и PKGBUILD для Arch Linux.

При первом запуске история, настройки, постеры и база TorrServer копируются из версии 0.5.8. Исходный профиль Electron не изменяется и может использоваться как резервная копия.

## English

Pirate Cinema 0.6.0 replaces the Electron client with the native Rust and Dioxus application. TorrServer/RuTor and Jackett/Prowlarr search, library metadata, MPV IPC, playback history, backups, updates, and tray behavior remain available.

Windows includes offline and compact web installers. Linux includes DEB, RPM, a portable archive/install script, and an Arch Linux PKGBUILD.

On first launch, history, preferences, posters, and TorrServer data are copied from version 0.5.8. The original Electron profile is left unchanged as a fallback.
