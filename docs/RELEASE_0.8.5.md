# Pirate Cinema 0.8.5

- Выбор источника поиска — RuTor, настроенный Torznab или Torrents.csv. Выбор сохраняется.
- Отдельный поиск Torrents.csv с обработкой следующих страниц.
- Поиск по локализованному и оригинальному названиям, объединение результатов и проверка указанного года.
- Torznab использует категории из t=caps, включая анимацию и общие категории индексеров.
- Исправлена поддержка раздач, для которых Jackett возвращает ссылку на torrent-файл вместо magnet.
- Размеры раздач Torznab отображаются в GiB/MiB, включая размер из enclosure.
- Устаревшие ответы поиска больше не подменяют новую выдачу, описание и постер.
- Исправлена сетка страницы поиска. Выбор источника компактно размещён у заголовка.
- Выпадающие меню получили тёмную нейтральную палитру.

Пакеты — основной Windows-установщик x64 и Linux AppImage x86_64.

Известные ограничения — полнота выдачи зависит от индексера. При отсутствии категории тип контента определяется приблизительно. Тяжёлые раздачи могут долго буферизоваться, производительность Linux требует дальнейшей работы.
