# Pirate Cinema 0.7.7

Выпуск переводит настольное приложение на полностью встроенную цепочку воспроизведения.

- TorrServer заменён встроенным `librqbit` 8.1.1.
- MPV заменён ArtPlayer и локальным HLS, который подготавливает FFmpeg.
- Сохранены выбор сезона, серии и аудиодорожки, продолжение просмотра, автопереход и полноэкранный режим.
- Исправлены запуск loopback-потока, бесшовная смена серии и завершение FFmpeg/торрент-сессии при закрытии.
- Устранены гонки, при которых отменённый поток мог снова открыть плеер или остановить новую серию.
- Сохранены локальная SQLite-история, постеры, описания, импорт прежнего профиля и поддержка `magnet:`.
- Windows-пакет содержит FFmpeg и Visual C++ Runtime; TorrServer, MPV и GStreamer больше не входят в установщик.
- Linux выпускается одним x86_64 AppImage и использует системные FFmpeg, GTK и WebKitGTK 4.1.

Пользовательские базы, кэши и ключи в релиз не включаются.
