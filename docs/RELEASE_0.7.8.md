# Pirate Cinema 0.7.8

Выпуск завершает очистку настольного приложения после перехода на встроенный движок.

- Переработана страница онлайн-просмотра: компактный поиск, продолжение просмотра, сохранённые плейлисты и аккуратная сетка результатов.
- История онлайн-просмотра и прогресс сохраняются локально и восстанавливаются после перезапуска.
- Удалены неиспользуемые настольные модули TorrServer и MPV, а также устаревшие поля настроек.
- Поиск раздач по-прежнему работает через локальный индекс и необязательный Jackett/Torznab, а воспроизведение — через встроенный librqbit и ArtPlayer/FFmpeg HLS.
- Сохранены SQLite-история, постеры, описания, импорт прежнего профиля и поддержка `magnet:`.

Пользовательские базы, кэши, ключи и сгенерированные установщики в репозиторий не включаются.
