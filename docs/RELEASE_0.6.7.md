# Pirate Cinema 0.6.7

## Русский

- Обновление главной больше не блокируется долгой синхронизацией медиатеки.
- Для зависающего публичного каталога Cinemeta действует короткий таймаут с переходом на локальный кэш или встроенный список.
- Полное обновление описаний и постеров показывает прогресс по карточкам вместо неподвижного состояния.
- Metadata, поиск и постеры Cinemeta продолжают использоваться независимо от доступности общего каталога.
- Для Linux публикуется AppImage, для Windows — основной офлайн-установщик.

## English

- Home refresh is no longer blocked by a long library metadata sync.
- The stalled public Cinemeta catalogue now has a short timeout and falls back to the local cache or bundled list.
- Full description and poster refresh now reports per-card progress instead of appearing frozen.
- Cinemeta metadata, search, and poster endpoints remain available independently of the main catalogue.
- Linux ships as AppImage and Windows ships as the main offline installer.
