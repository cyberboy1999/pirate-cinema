# Pirate Cinema 0.8.6 — исправление запуска раздач на Windows

Исправлена ошибка встроенного librqbit: Windows UDP `10054 ConnectionReset` от одного недоступного DHT-узла завершала поиск пиров целиком. Из-за этого раздачи оставались без данных, а FFmpeg выдавал ошибку подготовки потока `-138`.

Теперь DHT продолжает работу после этой ошибки. Другие ошибки обрабатываются как прежде. Изменение относится только к Windows; поведение Linux не изменено.

Проверено локально: заполнение таблицы DHT, воспроизведение раздачи и переход к следующей серии, Rust- и JavaScript-тесты.

Медиатека, настройки и история просмотра сохраняются.
