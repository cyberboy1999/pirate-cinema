# Pirate Cinema 0.6.6

## Русский

- На главной странице появилась компактная кнопка обновления рядом со стрелками каталога. Она обновляет популярное, постеры, медиатеку и историю просмотра без перезапуска приложения.
- Кнопки «Добавить» и «Смотреть» в результатах поиска теперь выделены белым цветом, как кнопка «Запустить» в карточке файла.
- Для Linux публикуется только AppImage, для Windows — только основной офлайн-установщик.

## English

- The home page now has a compact refresh button beside the catalogue arrows. It refreshes popular titles, posters, the library, and playback history without restarting the application.
- The Add and Watch buttons in search results now use the same solid white emphasis as the file-card Play button.
- Linux ships only as AppImage; Windows ships only as the main offline installer.
