## Русский

Pirate Cinema 0.6.1 делает основную кнопку «Запустить» в карточке фильма и серии полностью белой, чтобы она заметно отличалась от второстепенных элементов. Автопереход к следующей серии доступен для любой многофайловой раздачи.

Доступны автономный и web-установщик Windows, а также DEB, RPM, переносимый Linux-архив со скриптом установки и PKGBUILD для Arch Linux. Обновление сохраняет медиатеку, историю просмотра, настройки и базу TorrServer.

## English

Pirate Cinema 0.6.1 gives the main Play action on movie and episode cards a solid white treatment so it remains distinct from secondary controls. Automatic next-episode playback is available for every multi-file torrent.

The release includes Windows offline and web installers, plus DEB, RPM, a portable Linux archive/install script, and an Arch Linux PKGBUILD. Updating preserves the library, playback history, preferences, and TorrServer data.
