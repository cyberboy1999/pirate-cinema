# Pirate Cinema 0.7.9

Выпуск укрепляет встроенное воспроизведение и первый поиск после чистой установки.

- Загруженные librqbit видеоданные теперь удаляются после закрытия последнего потока, но metainfo раздачи сохраняется для повторного запуска, включая импортированные и частные `.torrent`.
- Остатки временного видеобуфера после аварийного завершения очищаются при следующем запуске; SQLite-история, описания и постеры не затрагиваются.
- Исправлено восстановление сессии librqbit на Windows: подготовленный JSON теперь атомарно заменяется через системную операцию Windows без риска обнулить сохранённую сессию.
- Холодная загрузка публичного поискового индекса получила реалистичный ограниченный таймаут в три минуты.
- Живой тест подтвердил 60 результатов для «Тачки» после холодной загрузки индекса.
- Расширенный owned-fixture smoke подтвердил запуск HLS, перемотку, бесшовный переход на следующую серию, сохранение прогресса и корректное завершение локальных процессов.
- README и GitHub About описывают актуальную архитектуру Rust/Dioxus: встроенный librqbit, FFmpeg HLS, ArtPlayer и SQLite.

Windows-релиз содержит основной NSIS-установщик с FFmpeg и Visual C++ Runtime. Linux-релиз содержит AppImage и использует системные зависимости, перечисленные в README. Пользовательские базы, кэши, ключи и установочные артефакты в репозиторий не включаются.
