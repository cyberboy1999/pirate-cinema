# Pirate Cinema 0.8.4

- Исправлено продолжение просмотра при восстановлении сохранённой озвучки: позиция больше не сбрасывается на начало до загрузки видео.
- Названия и языки аудиодорожек извлекаются из метаданных файла; при отсутствии названия остаётся номер дорожки.
- Популярные фильмы на главной приведены к единому размеру постеров 2:3 с увеличенными отступами.
- Двойной щелчок по заголовку миниплеера возвращает страницу воспроизведения без пересоздания плеера.
- Диагностика дополнена размерами SQLite и кэша постеров; в Linux — свободным местом и проверкой GStreamer H.264/AAC.

Windows: основной установщик x64. Linux: AppImage x86_64; системные зависимости и кодеки перечислены в README.

Известное ограничение: отдельные тяжёлые раздачи могут долго буферизоваться; производительность Linux требует дальнейшей работы.
