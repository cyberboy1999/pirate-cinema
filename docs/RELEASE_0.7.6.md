# Pirate Cinema 0.7.6

## Онлайн-просмотр

- Отдельная страница поиска и воспроизведения общедоступных онлайн-видео.
- Открытие и сохранение плейлистов, компактный выбор сезона и серии.
- Локальная история, продолжение с сохранённой позиции и недавно просмотренные видео на главной.
- Запоминание качества, кнопка следующей серии за две минуты до окончания и настройка автоперехода.
- Повторная загрузка потока с сохранением позиции при сетевой ошибке.
- Действия истории: продолжить, с начала, просмотрено и удаление отдельных записей.

История остаётся на компьютере. Для просмотра нужен доступный открытый поток; ограничения источника не обходятся.

## Пакеты

- Windows x64: основной NSIS-установщик с GST-сборкой TorrServer и Visual C++ Runtime.
- Linux x86_64: AppImage. Системные зависимости перечислены в README.

История и настройки существующей установки сохраняются при обновлении.
