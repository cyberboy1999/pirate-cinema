# Pirate Cinema 0.7.5 — исправления TorrServer и диагностика

- Локальный TorrServer запускается и перезапускается на `127.0.0.1:8091`. Прежний стандартный адрес 8090 переносится автоматически; пользовательские адреса сохраняются.
- Компактный перезапуск под индикатором подключения и в настройках. Приложение перезапускает только собственный сервер, не затрагивая внешние процессы.
- Исправлен отказ запуска Windows GST TorrServer при случайном выборе зарезервированного UDP-порта. Повторный запуск использует доступный порт торрент-соединений, не меняя HTTP-порт 8091 или сохранённые настройки.
- Индикатор проверяет доступность сервера и становится красным после падения. Устаревшие ответы до перезапуска больше не возвращают ложный статус «онлайн».
- Диагностика показывает состояние `/echo`, встроенного GStreamer, порта, процесса и последнего запуска. Копируемый отчёт исключает сырые логи, пути профиля, ключи и данные медиатеки; ничего не отправляется автоматически.
- Windows поставляется только с GST-версией TorrServer, без обычного сервера и запасного переключения на него.

Windows: основной установщик x64. Linux: AppImage x86_64; системные зависимости описаны в README. Пользовательская медиатека, история и настройки сохраняются при обновлении.
