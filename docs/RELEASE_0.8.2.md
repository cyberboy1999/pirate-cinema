# Pirate Cinema 0.8.2

## Русский

- На главную возвращены популярные фильмы Cinemeta: компактный ряд из 18 постеров в текущем дизайне.
- Нажатие на фильм запускает поиск раздач по его названию.
- Загрузка выполняется в фоне; при ошибке доступна кнопка повтора.
- Сохранены локальные обложки, коллекции и встроенный плеер.

## English

- Restored popular Cinemeta movies on Home as a compact row of 18 posters.
- Selecting a movie starts the existing torrent search with its title.
- Loading runs in the background and failed requests can be retried.
- Local cover modes, collections, and embedded playback are retained.
