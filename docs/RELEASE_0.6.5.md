# Pirate Cinema 0.6.5

Linux теперь распространяется одним AppImage, проверенным в чистом Arch Linux. Для Windows оставлен один автономный установщик. Исправлен запуск AppImage после удаления прежнего PKGBUILD-пакета: отсутствие системного трея больше не приводит к белому экрану, а команды установки Linux-зависимостей добавлены в README.

---

Linux now ships as one AppImage verified in a clean Arch Linux environment. Windows ships one offline installer. AppImage startup after removing the former PKGBUILD package is fixed: an unavailable system tray no longer causes a blank panic screen, and Linux dependency commands are documented in the README.
