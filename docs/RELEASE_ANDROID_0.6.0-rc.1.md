# Pirate Cinema Android 0.6.0-rc.1

Первый подписанный Android-кандидат с полностью встроенным librqbit и Artplayer. **Предварительный выпуск**, не обновление desktop-версии.

## Что входит

- Встроенный librqbit 9.0.1: magnet/.torrent, выбор файла, поток через loopback с HTTP Range, пауза/продолжение и восстановление сессии. Отдельный TorrServer не нужен.
- Artplayer для торрентов: выбор серии, разрешения и звуковой дорожки; локальные HLS-сегменты H.264/AAC и отдельная история каждого файла.
- Автопереход к следующей непросмотренной серии с запоминаемым переключателем; повторный magnet с тем же BTIH открывает существующую раздачу без перезаписи.
- RuTube: ссылки, поиск, сохранённые ролики и загруженные очереди плейлистов, качество и продолжение просмотра.
- Компактное приподнятое нижнее меню, настройки языка и режима TV.
- Foreground-служба с действием остановки, корректным восстановлением из приложения и защитой диска: мягкий лимит 8 ГБ (меняется в настройках), резерв 512 МБ. Проверка каждые пять секунд; при превышении загрузки приостанавливаются, файлы автоматически не удаляются.
- При удалении раздачи можно отдельно удалить её загруженные файлы.
- Резервные копии истории, описаний и RuTube; проверка структуры, откат при переполнении хранилища и отмена последнего восстановления.
- Передача названий торрентов в Cinemeta отключена по умолчанию и требует явного согласия. Автоматическое облачное резервирование отключено.

## Установка

APK для **arm64-v8a**, Android 7+ с актуальным Android System WebView. Сверьте SHA256SUMS перед установкой. Кандидат подписан постоянным release-ключом; будущие выпуски будут использовать тот же ключ.

SHA-256 сертификата подписи:
`32016ceab8dc23c62cd7736d09834fe8ce8c8ff2e1ff0ea7365ec8b1f782fc76`.

Релиз нельзя поставить поверх старой **debug**-сборки с другой подписью. Сначала экспортируйте резервную копию и сохраните нужные торрент-файлы; не удаляйте старое приложение, пока данные не сохранены. JSON-копия не содержит скачанные видео и приватные tracker credentials.

## Известные ограничения

- На устройстве проверяется arm64 / Android 16; остальные версии Android и TV не прошли отдельную аппаратную матрицу.
- Совместимость достигается перекодированием на телефоне: возрастает нагрузка/расход батареи; сохранение HDR, surround и всех субтитров не заявляется. Полная матрица HEVC/AC3/DTS не проверена.
- RuTube зависит от доступности публичного API; длинные плейлисты нужно догружать кнопкой «Загрузить ещё». Торрент-поискового провайдера в librqbit нет: используйте magnet/.torrent.
- Android может ограничить время foreground data-sync службы. Удаление задачи из списка недавних останавливает принадлежащий ей движок; автоматического запуска при загрузке телефона нет.
- Полный repository test: 59/61; два известных сбоя относятся к прежним desktop installer/workflow assertions, а не к Android. Мобильные unit-тесты: 16/16.

## Проверка на устройстве

Подписанный QA-вариант прошёл 20 минут непрерывного воспроизведения на Android 16: кадры и позиция продолжали расти, паузы не было, максимальный PSS — 367 065 КиБ. Отдельно прошли 6/6 инструментальных проверок: нативный FFmpeg/HLS, Stop → Restart, работа в фоне и реальное пересечение лимита диска на 1 ГиБ при уже приостановленной первой раздаче.

Точные выполненные аппаратные проверки и их ограничения: `LIBRQBIT_ANDROID_TEST_REPORT.md`. Инструкции сборки и подписи: `docs/ANDROID_RELEASE.md`. Исходники соответствуют коммиту релиза; ключи, пользовательские базы и тестовые видеоматериалы в них не включены.
