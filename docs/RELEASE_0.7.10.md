# Pirate Cinema 0.7.10

Выпуск исправляет потерю качества во встроенном ArtPlayer при подготовке локального HLS.

- FFmpeg больше не принудительно снижает частоту кадров каждого видео до 24 fps; сохраняется частота кадров исходного файла.
- Качество обязательного браузер-совместимого H.264 повышено с CRF 23 до визуально прозрачного CRF 18.
- Исходное разрешение сохраняется; нечётный размер корректируется только до ближайшего чётного пикселя, необходимого libx264.
- Живой локальный тест подтвердил сохранение 60 fps, запуск первого сегмента, перемотку, переход между двумя сериями, запись истории и чистое завершение librqbit/FFmpeg.

Windows-релиз содержит основной NSIS-установщик с FFmpeg и Visual C++ Runtime. Linux-релиз содержит AppImage и использует системные зависимости, перечисленные в README. Пользовательские базы, кэши и установочные артефакты в репозиторий не включаются.
