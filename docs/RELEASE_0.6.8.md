# Pirate Cinema 0.6.8 — Windows Fix

## Русский

- Встроенный TorrServer больше не завершается из-за временной ошибки включения необязательного поиска RuTor.
- Обновление из приложения теперь корректно показывает системный запрос UAC и запускает основной NSIS-установщик вместо ошибки Windows 740.
- Медиатека, история просмотра, настройки и база TorrServer при обновлении сохраняются.

В релиз входят основной установщик Windows x64 и Linux x86_64 AppImage.

## English

- The bundled TorrServer no longer exits when the optional RuTor setting cannot be enabled temporarily.
- In-app updates now request elevation through Windows UAC and launch the production NSIS installer instead of failing with Windows error 740.
- Library data, playback history, settings and TorrServer data are preserved during upgrades.

The release contains the Windows x64 installer and Linux x86_64 AppImage.
